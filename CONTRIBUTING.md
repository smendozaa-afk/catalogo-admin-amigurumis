# Cómo contribuir a este proyecto

¡Gracias por tu interés en ayudar a mejorar el Catálogo Administrativo Web de Amigurumis!

## Pasos para aportar una mejora
1. Revisa los **Issues** abiertos para asegurarte de que nadie más esté trabajando en lo mismo.
2. Si tienes una propuesta nueva, abre un **Issue** explicando claramente el cambio que sugieres.
3. Crea una rama (branch) separada de `main` para trabajar en tu modificación.
4. Cuando termines, abre un **Pull Request** para que el equipo pueda revisar y aprobar tu aporte.

¡Toda ayuda es bienvenida!
